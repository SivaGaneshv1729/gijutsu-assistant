# ADR-006: Why No Physical IoT in V1

## Status
Accepted

## Context
The platform aims to provide engineering intelligence. While integrating live machine telemetry (OPC-UA, MQTT sensors) is the long-term vision, it introduces massive complexity involving time-series databases, streaming architectures, and physical hardware simulation.

## Decision
Version 1 focuses purely on the **Knowledge Management and Retrieval** aspect using static documents (manuals, guidelines). Live IoT data is explicitly excluded from V1.

## Consequences
- **Pros**: Sharply reduces scope, allowing the team to perfect the core Document Knowledge, Hybrid RAG, and UI components first. The architecture remains extensible for future telemetry integration.
- **Cons**: The demo will rely on user-provided scenarios rather than live machine data triggering insights automatically.
