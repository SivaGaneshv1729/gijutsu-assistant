# ADR-007: Free LLM via Hugging Face Inference API

## Status
Accepted

## Context
The RAG pipeline needs a text-generation model to convert retrieved chunks into polished, grounded answers. The initial codebase imported `openai` and referenced a `gpt-4o` configuration, but no LLM call was implemented — answers were mocked by concatenating retrieved text. Paid APIs (OpenAI, Anthropic) carry per-token costs, which conflicts with the requirement to run the platform at **zero cost**.

## Decision
Use the **Hugging Face Inference API** (free tier) as the default LLM provider:

- Call `https://api-inference.huggingface.co/models/{HF_MODEL}` over HTTPS.
- Default model: `google/flan-t5-large` (fast, effective instruction following).
- Authentication via a free personal token (`HF_TOKEN`).
- If `HF_TOKEN` is unset or the inference call fails repeatedly, fall back to an **extractive answer** (the top matching chunk), so the platform remains functional without any external dependency.

## Consequences
- **Pros**: Zero license or usage cost. Model is configurable via a single environment variable. The implementation uses plain HTTPS (`httpx`), so no heavyweight SDK dependency.
- **Cons**: Free-tier inference is rate-limited and slower than paid APIs; cold starts return `503` until the model loads. Answer quality is below frontier commercial models. The fallback path may return verbose raw text instead of a synthesized answer.
