# ADR-001: Why Spring Boot + Python AI Service

## Status
Accepted

## Context
The platform requires both enterprise business logic (RBAC, workflows, APIs) and advanced Machine Learning logic (RAG, vector embeddings, chunking, graph orchestration).
Attempting to do this in a single language often involves compromises: Python lacks robust enterprise tooling compared to Java, and Java's ML ecosystem is much weaker than Python's.

## Decision
We will use a modular monolithic approach utilizing two services:
1. **Spring Boot (Java)**: Handles user management, RBAC, data persistence, and API orchestration.
2. **FastAPI (Python)**: Specialized AI Service for embeddings, retrieval, reranking, parsing, and LLM interaction.

## Consequences
- **Pros**: Clean separation of concerns. Leverages the best ecosystems for both domains. Scalable independently.
- **Cons**: Slightly increased architectural complexity and deployment overhead compared to a single monolith.
